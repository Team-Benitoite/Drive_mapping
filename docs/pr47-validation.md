# PR #47 統合・修正の検証記録

2026-10-31、TypeScript移行ブランチへmainの `ec14b32` を統合しました。

## 統合方針

- mainの地図、ドラッグ・ズーム、人気投稿の吹き出し、ヘッダーメニューをTypeScriptで維持。
- お気に入りの保存先は `supabase/schema.sql` に存在する `route_likes` を使用。UIの「お気に入り」表記は維持し、DBテーブルの追加・改名は行わない。
- 存在しない `like_count`、`photo_path` の参照を除去。人気表示は各都道府県の最多お気に入り投稿から上位3件を選び、写真は `storage_path` / `thumb_path` から取得する。
- 投稿をページ単位で取得して件数と人気順を集計。データ量が大きくなった場合はDB側の集計へ移す余地がある。

## 修正

- 検索の戻る・進むでURL、入力値、検索結果を同期。遅れて到着した古い検索応答は表示へ反映しない。
- 検索演算子の誤記 `ifavorite` を `ilike` へ修正。
- お気に入り保存・解除の失敗理由を詳細画面内に表示し、再試行可能にする。
- メニューを閉じるクリック処理とSPA遷移を両立。メニューにお気に入り一覧への導線を追加。
- 地図のホイール操作、キーボードでの都道府県選択、吹き出しの行間を修正。
